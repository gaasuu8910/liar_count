# ライアーカウント

嘘で降ろせ。見破られたら、運と度胸に賭けろ。

ブラウザで遊べるオンライン対戦版です（2〜6人）。

- `index.html`：オンライン対戦。部屋を作り、部屋コードか招待リンクを友達に送って、各自のスマホから参加する
- `solo.html`：ボット3人と練習

## オンライン対戦のしくみ

- サーバーは不要です。部屋を作った人（ホスト）のブラウザがゲームを進行し、参加者とは WebRTC（PeerJS）で直接つながります
- 各プレイヤーには、自分に見えてよい情報（自分の手札など）だけが送られます
- ホストが画面を閉じたりスリープしたりすると、ゲームが止まります。ホストは画面をつけたままにしてください
- 参加者が切断しても、同じ端末から部屋に入り直せば、同じ席に戻れます。切断中の手番は自動で進みます

## ルール

1. 手番では「自分の手札3枚＋あと1枚の合計は○以上」と宣言する。前より大きい数字で、上げた数だけチップを払う（最初の宣言は1枚）。宣言しないなら降りる。
2. 宣言の直後、次の人が動く前なら、誰でも早い者勝ちで「ライアー」と言える（降りた人は除く）。
3. 誰にもライアーと言われず手番が自分まで一周したら、手札を見せずにポット総取り。
4. ライアーと言った人は手札を伏せて混ぜ、宣言者が1枚引いて自分だけで見る。残りの2枚は見ずに捨てる。届いたと言い張るなら「チェック」、諦めるなら「フォールド」。
5. チェックされたら、ライアーと言った人は「受ける」か「引く」。受けたら公開し、手札3枚＋引いた1枚が宣言以上なら宣言者の勝ち。負けた側は追加で払う。ライアーが外れたら、宣言を超えていた分を。宣言者が届かなかったら、ポットと同額を。引いたら宣言者がポットを取り、カードは誰にも見せない。

- カード：1〜9が各4枚、「−5」が2枚、「×2」が2枚（×2は他の札の合計を2倍、2枚なら4倍）
- 各自3枚、チップ10枚。毎ラウンド参加料1枚。ライアーと言うのは無料

## 開発メモ

ローカルでのテストは、PeerJS サーバーを立てて `?signal=127.0.0.1:9000` を付けて開きます（`&speed=6` で進行を速くできます）。
