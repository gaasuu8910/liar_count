# ライアーカウント（LIAR COUNT）

嘘で降ろせ。見破られたら、運と度胸に賭けろ。

ブラウザで遊べるテストプレイ版です。`index.html` を開くと、ボット3人と対戦できます。

## ルール

1. 手番では「自分の手札3枚＋あと1枚の合計は○以上」と宣言する。前より大きい数字で、宣言ごとにチップ1枚。宣言しないなら降りる。
2. 誰にもライアーと言われず手番が自分まで一周したら、手札を見せずにポット総取り。
3. 誰かが「ライアー」と言ったら、その人は手札を伏せて混ぜ、宣言者が1枚引いて自分だけで見る。残りの2枚は見ずに捨てる。届いたと言い張るなら「チェック」、諦めるなら「フォールド」。
4. チェックされたら、ライアーと言った人は「受ける」か「引く」。受けたら公開し、手札3枚＋引いた1枚が宣言以上なら宣言者の勝ち。負けた側はポットと同額を追加で払う。引いたら宣言者がポットを取り、カードは誰にも見せない。

- カード：1〜9が各4枚、呪い札「−5」が4枚
- 各自3枚、チップ6枚。毎ラウンド参加料1枚。ライアーと言うのは無料
